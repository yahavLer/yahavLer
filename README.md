### Personality Match – Final Project

A full-stack **matchmaking platform** developed as a final project, combining a native Android application with a microservices-based backend.

The system includes registration and authentication, MBTI personality analysis, lifestyle and preference questionnaires, match recommendation flows, chat, profile management, and notification features.  
The backend was designed as a multi-service architecture handling user flows, personality processing, matchmaking logic, chat services, and face-similarity integrations.

**Tech:** Android, Java, Firebase, Retrofit, XML, Gradle, Spring Boot, Python, FastAPI, TypeScript, PostgreSQL, MongoDB, Docker Compose

- Android Client: [Meeting_Final_Project_Android](https://github.com/yahavLer/Meeting_Final_Project_Android)
- Backend Microservices: [serverMatchmakingMicroservices](https://github.com/yahavLer/serverMatchmakingMicroservices)
